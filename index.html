新增 / 編輯品質平台看板

Google Sheet 雲端資料庫設定

請貼入 Google Apps Script 部署發布的 Web 應用程式網址 (Web App URL)。設定後，新增/修改資料將即時與 Google 試算表同步。

如何取得 API 網址？
1. 開啟專案資料夾內的 google_apps_script.js 並複製全數程式碼。
2. 開啟 Google 試算表 ➔ 點「擴充功能」➔「Apps Script」貼上程式碼並儲存。
3. 點右上「部署」➔「新增部署」➔ 種類選「Web 應用程式」，存取權限選「所有人(Anyone)」。
4. 複製獲得的 Web App URL 並貼於上方點擊儲存連線！
